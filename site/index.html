Features

Keep every agent working, and every change in hand.

Sessions side by side, each on its own branch, with Git, plan limits and your servers in the same window.

When one runs out, the next carries on

See each agent's plan limits, when they reset and when they'd run out at your pace. If an agent runs out mid-turn, another account or agent picks the conversation up where it stopped.

Undo any turn

Each turn is checkpointed. Put the files back exactly as they were before it, and undo the undo if you change your mind.

A worktree per session

Sessions can each work on a branch of their own, so two agents never trip over each other. ⌘T starts one on a new branch; ⌘K jumps to any session.

Git, built in

Changes, history and search, a pull request in one click, and cloning as in GitHub Desktop. Comment on a diff line and the agent gets it straight away.

One prompt, several agents

Send the same task to Claude Code, Codex and Cursor at once, each in its own worktree, and keep the best answer. Mission Control (⇧⌘M) shows every session that needs a look.

Servers, kept out of reach

Servers open as terminals in their project, with passwords in your Mac's Keychain. Agents can't reach them, except read-only on the servers where you turn that on.

Prompts on a schedule

Run a prompt every morning, or the moment a usage limit resets. A session can carry on by itself once its agent can work again.

Limits and cost, at a glance

Usage for every agent and account in the sidebar, a warning once a limit passes 90%, and what your sessions would have cost at API prices.

Private by design

No server of its own. No telemetry.

Your code goes to the agents you choose, under your own accounts, and nowhere else.

  • Agents run through their official CLIs, signed in on your Mac.
  • Besides the agents, the app talks only to GitHub, to Cursor's usage service if you turn its meters on, and to the licence service to activate a key.
  • Passwords and tokens stay in your Mac's Keychain, never in files or the cloud.
  • Not affiliated with Anthropic, OpenAI, Cursor, GitHub or Google.

Install

Up and running in a minute.

Download and drag

Open the DMG and drag Mountagent Desk to Applications. It needs macOS 14 or later.

Open it once

The app isn't notarized yet, so the first time macOS stops it: click Done, then Open Anyway in System Settings → Privacy & Security. Updates don't ask again.

Sign in to your agents

Sign in once to the CLI of each agent you use, such as claude for Claude Code. The app uses those sign-ins.

Questions

Good to know

Does it cost anything on top of my agent plans?

No. Mountagent Desk drives each agent's own CLI with your own sign-in, so your existing plans (Claude Pro or Max, ChatGPT, Cursor, Copilot…) are all it uses. The app itself is free, with Pro as a one-time purchase.

Which agents does it work with?

Claude Code, Codex, Cursor, GitHub Copilot, Antigravity, Gemini CLI and OpenCode, with chat, models and limits for each. Any other command, such as Kiro, Amp, Kimi Code, Grok Build, Mistral Vibe or Droid, runs as a terminal session beside them.

Is my code sent anywhere?

Only to the agents you use, as their CLIs normally do. Mountagent Desk has no server of its own and collects no telemetry.

What does Pro add?

The free version runs up to three agents at a time with one account each. Pro runs every agent with as many accounts as you like, on the Macs you use, for one payment and updates for life.

How do updates work?

The app checks once a day and shows an Update button when a new version is out. Releases and what each one brought are on GitHub.
